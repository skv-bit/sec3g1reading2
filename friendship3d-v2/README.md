# 《手表》· 3D友情侦探（已恢复可走动版）

在线入口：https://skv-bit.github.io/sec3g1reading2/friendship3d-v2/

## 当前游戏：真3D可走动版

2026-10-30，按教学需求恢复之前的 **可走动 3D 版本**，原因是 2.5D 插画在全屏显示下显得模糊。网站现在再次使用 Three.js + 原有 GLB 模型（`world-three.js`），保留轻快背景音乐、正确答案音效和中文女声选择，以及 I Do / We Do 两关共 7 个任务触发点（10 个阅读活动步骤）。

### 操作
- **W A S D / 方向键**移动
- **Shift** 快跑
- **拖动鼠标**旋转镜头；滚轮缩放
- **E** 靠近当前发光线索后互动
- **R** 恢复镜头，右上角「恢复画面」可同时重置玩家位置
- 关卡题目、进度和侦探笔记均保留浏览器本地存储，教师控制台可演示跳转

## 备用版本

2.5D 实验文件 `storyworld-2d.js` 和 `style-illustrated.css` 暂时仍保留在目录中，但当前 `index.html` **不引用它们**。未来如需局部采用绘本美术，可在 3D 界面中的题目弹窗复用 `assets/art/` 插画，不必放弃走动体验。

## 注意

真实 3D 模型五官、骨骼尚属低模原型，不等同于高品质插画；若需要后续提高画质，应优先改进 GLB 五官贴图、材质与动画，而不是再次牺牲自由移动。
