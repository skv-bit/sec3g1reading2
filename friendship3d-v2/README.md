# 《手表》友情侦探 · 2.5D绘本式互动游戏

当前版本：2026-10-30 绘本版。在线入口：https://skv-bit.github.io/sec3g1reading2/friendship3d-v2/

## 本次改版

- 不再加载低模GLB人物与WebGL场景；采用用户原有的**两张精美插画**作为校园与丽华家门口主场景。
- 轻微视差与镜头平移、发光互动标记、点击线索后柔和推进；不必跑到物品旁边才能作答。
- 保留七个互动触发点、十个阅读步骤；第一关 I Do：脚踏车→手表→丽华；第二关 We Do：妈妈引导→门铃→丽华→证据集合站。
- 保留题目、拼音/English、生词、证据回看、差异化侦探笔记、三项自评与初稿/修订稿本地保存。
- 保留轻快原创校园循环音乐、答对音效、中文女声语音选择（具体取决于设备已安装的系统音色）。
- 不再依赖WebGL，所以之前移动画面空白的故障类型在这版被避开了。

## 操作说明

直接点击发光的故事物品或人物。WASD/方向键也可轻移探索指示点，E进入当前任务，R复位。若遮挡场景，可点击左侧任务栏的 - 收起，或 + 展开。

无需联网音频/3D CDN。本站属于静态网页，进度储存在本机浏览器，学生可下载匿名JSON记录。课堂使用前请在目标设备测试语音与显示比例。

原有 3D 实验代码（`world-three.js`、旧GLB模型及旧游戏引擎）保留在仓库中，但当前页面不会载入它们。
