# 光之线索｜《手表》3D友情侦探

这是从零编写的原创 Three.js 网页互动阅读游戏，不复制以前的游戏源码、UI 或素材文件。角色和环境由代码实时生成，是可以操作的3D世界，不是贴在背景上的平面截图。

## 网页地址

若仓库的 GitHub Pages 已设置为由 main 分支根目录发布：
https://skv-bit.github.io/sec3g1reading2/friendship-quest-3d/

如 Pages 尚未启用，该地址暂时可能出现404。GitHub 仓库中的代码已创建，但不能把仓库上传等同于网站发布成功。

本地方式：在仓库根目录运行 python3 -m http.server 8000，然后打开 http://localhost:8000/friendship-quest-3d/ 。需要网络加载 Three.js v0.160.1 公共 CDN 模块。

## 游戏玩法

- WASD 或方向键走路，Shift 跑步。
- 鼠标拖动旋转镜头、滚轮缩放，移动端提供屏幕方向键。
- 靠近三维发光线索后点击/按E打开任务。
- 第一关 I Do：蓝色脚踏车 → 手表 → 丽华。
- 第二关 We Do：妈妈（回忆教学向导）→ 门铃 → 丽华 → 证据集合站。
- 单选、多选、词语选择、动作语言归类；客观题完成后解锁下一题。
- 三级侦探笔记支架、三项自我评估、匿名浏览器进度保存与本地 JSON 导出。
- 开放性回答不按关键词机械判对错，需教师讨论与评价。

## 独立程序目录

- index.html：网页入口。
- style.css：响应式界面。
- game.js：原创 Three.js 三维环境、程序化 Q版人物、运动与答题机制。
- README.md：此说明。

人物肢体移动为程序化简化动画，并非骨骼动画；角色与道具没有使用此前的GLB模型。Three.js 是公用三维引擎，游戏代码及美术构造均重新编写。

## 限制

课文节选必须在正式课堂使用前由老师和教科书再次核对。这里的妈妈是教学引导角色，并非原文故事中妈妈陪“我”到丽华家。程序已通过基础 JS 语法检查，但真实浏览器/GitHub Pages发布状态、手机性能和碰撞体验仍需实测确认。
